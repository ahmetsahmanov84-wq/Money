# Money Tracker — Трекер денег

PWA для iPhone и iPad. Работает без интернета, данные хранятся на устройстве (IndexedDB).

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите в его корень все файлы из архива (вместе с папками `css`, `js`, `assets` и файлом `.nojekyll`).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт откроется по адресу `https://<имя>.github.io/<репозиторий>/`.

## Установка на iPhone
1. Откройте адрес в Safari.
2. «Поделиться» → «На экран „Домой“» → «Добавить».
3. Запустите приложение один раз с интернетом: после этого оно работает офлайн.

## Обновление
При изменении файлов увеличьте `VERSION` в `service-worker.js`, иначе телефон продолжит показывать старую версию из кэша.
